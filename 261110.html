지난 사업의 보고서나 예산 파일, 지금 바로 찾을 수 있나요? 전임자가 저장한 문서는 어디 있나요?

문제 인식 3분

인수인계 때 "USB 하나 받았다", "바탕화면 폴더 하나 받았다"는 경험을 물어봅니다.

"업무 히스토리가 끊기면 처음부터 다시 배우거나 같은 실수를 반복하게 됩니다."

자료는 사람이 아니라 조직이 가져야 합니다

사람 중심 관리조직 중심 관리

원본 강의안 5~7번 슬라이드("왜 반복될까요? 사람 중심이었기 때문")를 비교표 하나로 묶었습니다.

오른쪽 칸이 오늘 2·3모듈의 목표 상태라고 말해 둡니다.

'소유자'를 알아야 자료를 지킵니다

파일을 만든 계정이 소유자

공유받은 사람이 아무리 많아도 파일의 주인은 처음 만든 계정입니다.

소유자 계정이 사라지면

개인 계정이 삭제되면 그 계정이 소유한 파일도 함께 사라질 수 있습니다.

퇴사 전에 소유권 이전

공유 설정에서 다른 직원을 소유자로 지정할 수 있습니다. 상대가 수락해야 완료됩니다.

기관 차원의 해법

핵심 폴더는 기관 공용 계정이 소유하게 합니다. 기관 소유 '공유 드라이브'는 다음 과정에서 다룹니다.

원본 강의안에 없던 핵심 개념입니다. "자료가 사람과 함께 사라지는" 기술적 이유가 바로 소유권입니다.

공유 드라이브는 Google Workspace(비영리 프로그램 포함) 계정에서 쓰는 기능이고 일반 무료 계정에는 없습니다. 다음 과정에서 비영리 프로그램 신청과 관리자 콘솔을 다루므로 여기서는 예고만 합니다.
개인 계정 간 소유권 이전은 받는 사람이 수락해야 완료되는 방식입니다. 화면은 수업 전 확인 권장.

그대로 올릴까, 구글 형식으로 바꿀까

그대로 보관

  • Word·Excel·PDF를 원래 형식으로 저장
  • 드라이브에서 열어 보기와 간단한 편집 가능
  • 원본을 그대로 남겨야 하는 결재본·제출본에 적합
  • 출석관리 실습 시트 사본 만들기클릭 → 사본 만들기 → 내 드라이브에 저장
  • 후원물품관리 실습 시트 사본 만들기클릭 → 사본 만들기 → 내 드라이브에 저장

구글 형식으로 변환

  • 구글 문서·스프레드시트·프레젠테이션으로 변환
  • 동시 편집·댓글·버전 기록을 온전히 사용
  • 여럿이 함께 고쳐 나갈 문서에 적합
원칙: 함께 고칠 문서는 구글 형식으로, 확정된 원본은 그대로 보관합니다.

"엑셀 파일 올렸는데 왜 같이 수정이 안 되죠?"라는 질문을 미리 막는 슬라이드입니다.

변환 방법: 파일 열기 → 파일 메뉴 → Google 스프레드시트(문서)로 저장.

한글(HWP) 파일은 드라이브에 보관은 되지만 구글 문서에서 바로 편집할 수 없습니다. 질문이 나오면 "함께 고칠 문서는 처음부터 구글 문서로 작성"을 권하세요.

추가한 사람만 열 수 있습니다. 개인정보가 있는 문서의 기본값.

일반 액세스: 링크가 있는 모든 사용자

링크를 받은 누구나 열 수 있습니다. 공개해도 되는 자료에만.

1모듈 구글 포토 공유 앨범(협업·링크 두 스위치)과 비교해서 설명하면 이해가 빠릅니다.

강사 화면에서 공유 버튼을 눌러 실제 드롭다운을 보여 주세요.

공유할 때 지킬 네 가지

필요한 만큼만

기본은 뷰어. 편집자는 실제로 함께 쓰는 담당자에게만 줍니다.

개인정보 문서는 '제한됨'

이용자 명단·상담 기록은 사람을 지정해서만 공유합니다.

링크 공유는 기간을 정해

행사 신청 안내처럼 공개가 필요한 자료도 끝나면 '제한됨'으로 돌립니다.

정기 점검

분기마다 공유된 파일과 사람을 확인하고 정리합니다.

편집자는 기본적으로 다른 사람에게 다시 공유할 수 있습니다. 공유 설정의 톱니바퀴에서 '편집자가 권한을 변경하고 공유할 수 있음'을 끄면 막을 수 있습니다.

재공유 차단 설정은 의외로 모르는 분이 많아 시연을 권합니다.

사례 질문: "이용자 명단 스프레드시트를 '링크가 있는 모든 사용자 - 편집자'로 단톡방에 올리면 어떤 일이 생길까요?"

링크 주소를 읽을 줄 알면 편해집니다

파일 하나보다 폴더 하나를 공유합니다

권한이 그대로 이어집니다

폴더에 준 권한은 안에 있는 파일과 나중에 넣을 파일에도 적용됩니다.

링크 하나로 인수인계

사업 폴더 링크 하나만 넘기면 관련 자료 전체가 넘어갑니다.

단순하게 시작

사업별 폴더 한 단계부터. 이름 앞에 번호를 붙이면 순서대로 정렬됩니다.

기관 전체의 폴더 구조와 파일명 표준은 다음 과정(기관 직인 및 인증 문서 관리)에서 자세히 설계합니다.

원본 3모듈 9번 슬라이드(폴더 구조·파일명 규칙)는 다음 과정 4모듈과 겹쳐서 여기서는 '폴더 단위 공유'라는 원리만 다룹니다.

번호 정렬 예시: 01_운영 / 02_예산 / 03_홍보 — 말로만 짧게.

공유받은 폴더를 내 드라이브에 두기

바로가기 추가

공유 문서함의 폴더를 오른쪽 클릭 → 정리 → 바로가기 추가. 내 드라이브에서 바로 열립니다.

복사가 아니라 연결

바로가기는 원본으로 가는 길입니다. 용량을 쓰지 않고 내용도 늘 최신입니다.

사본과 헷갈리지 않기

사본은 새 파일이라 원본이 바뀌어도 따라 바뀌지 않습니다.

"공유받은 폴더가 어디 갔는지 모르겠다"는 가장 흔한 불편을 해결하는 기능입니다.

메뉴 경로(정리 → 바로가기 추가)는 화면 업데이트에 따라 다를 수 있습니다.

파일을 빠르게 찾는 법

검색창에 단어 입력

파일 이름뿐 아니라 문서 안의 글자도 검색됩니다.

검색 필터 사용

유형(문서·시트·PDF), 사람(소유자·공유한 사람), 수정 날짜로 좁힙니다.

PDF·이미지 속 글자

스캔한 PDF나 사진 속 글자도 인식해 찾아 주는 경우가 많습니다.

별표와 최근 문서함

자주 쓰는 양식은 별표. 방금 연 파일은 최근 문서함.

예시 시연: "작년 예산 엑셀" → 유형: 스프레드시트, 수정 날짜: 지난해.

이미지·스캔 PDF 속 글자 검색은 파일 상태에 따라 인식되지 않을 수 있습니다. "많은 경우"로 표현했습니다.

저장공간 관리와 PC 연결

큰 파일부터 정리

드라이브 왼쪽 '저장용량'을 누르면 용량이 큰 파일 순으로 보입니다.

휴지통도 용량

휴지통 파일은 30일 동안 용량을 차지합니다. 급하면 직접 비웁니다.

데스크톱용 Google Drive

PC에 설치하면 탐색기에 드라이브가 폴더처럼 나타나 끌어다 놓기로 올릴 수 있습니다.

동기화 주의

PC 동기화 폴더에서 지우면 클라우드에서도 지워집니다 (1모듈 동기화와 같은 원리).

데스크톱용 Google Drive 설치는 기관 PC 보안 정책에 따라 막혀 있을 수 있습니다. 설치 권장보다는 "이런 방법도 있다" 수준으로 소개합니다.

스마트폰에서 쓸 때

앱을 따로 설치

드라이브·문서·스프레드시트·프레젠테이션 앱이 각각 필요합니다.

계정 구분 확인

안드로이드 업무 프로필을 쓰면 개인 계정과 업무 계정이 나뉘어 보입니다. 앱 오른쪽 위 프로필로 확인합니다.

서류는 스캔으로

드라이브 앱의 + 버튼에서 스캔을 고르면 종이 서류를 PDF로 바로 저장합니다.

오프라인 사용

자주 보는 파일은 오프라인 사용을 켜 두면 인터넷 없이 열람할 수 있습니다.

원본 22번 슬라이드(스마트폰 유의사항)에 실무 기능 두 가지(스캔·오프라인)를 보강했습니다.

드라이브 앱 스캔 기능의 위치는 안드로이드와 iOS가 다를 수 있습니다. 시연하려면 수업 전 강사 휴대폰으로 확인하세요.

실습 A 더 하기: 링크·사본·폴더 공유

  1. 링크 복사공유 → 링크 복사 → 메모장에 붙여 넣어 주소 모양 확인
  2. 사본 만들기파일에서 오른쪽 클릭 → 사본 만들기 → 이름 바꾸기
  3. 폴더째 공유실습 폴더를 옆 사람에게 '뷰어'로 공유하고 안의 파일이 보이는지 확인
  4. 권한 거두기공유 설정에서 옆 사람을 삭제하고 다시 열리지 않는지 확인

원본 체크리스트에 없는 확장 단계입니다. 빨리 끝난 분 대상 과제로 써도 됩니다.

이유: 다음 과정의 영수증 관리 앱은 '시트 사본 만들기 → 폴더 만들기 → 폴더·시트 URL 복사'로 시작합니다. 오늘 익혀 두면 그 실습이 훨씬 빨라집니다.

원본 3모듈 9번(공유 체계 Tip: 공용 드라이브·폴더 구조·파일명)은 다음 과정 4모듈과 겹쳐서 '운영 약속' 중심으로 바꿨습니다.

따라 하기 1: 공유하기

  1. 구글 문서 열기빈 문서 또는 템플릿 선택
  2. 공유 버튼 선택
  3. 특정인을 편집자로 공유이메일 입력 → 편집자 선택 → 전송
  4. 링크로 누구나 열게제한됨 → 링크가 있는 모든 사용자
  5. 뷰어 → 편집자 바꾸기
  6. 링크 복사 후 완료
  7. 동시 접속자 확인오른쪽 위 프로필 아이콘

체크리스트 1~7단계. 4~5단계는 '실습용'이라 링크 편집자로 여는 것이며 실제 업무 문서에서는 2모듈 공유 원칙(필요한 만큼만)을 지키라고 꼭 덧붙입니다.

따라 하기 2: 댓글과 @멘션

  1. 문장 드래그 → + 댓글 추가
  2. 메모 입력 후 댓글 클릭
  3. 특정인에게 댓글다시 문장 선택 → 댓글 추가
  4. @ + 구글 계정 입력모둠원 지정
  5. 내용 입력 후 댓글
  6. 체크로 해결
  7. 해결된 댓글 다시 보기모든 댓글 보기
  8. 해결됨·해결 안 됨 걸러 보기

체크리스트 8~15단계. 모둠 샘플 문서에서 서로를 @멘션하게 하면 알림 메일이 실제로 도착하는 것을 확인할 수 있습니다.

따라 하기 3: 사본과 제안 모드

  1. 파일 메뉴 선택원본을 두고 사본을 만들 때
  2. 사본 만들기 클릭
  3. 제목 바꾸고 사본 만들기
  4. 수정 모드 클릭오른쪽 위 연필
  5. 제안 모드 선택결정권자가 아닐 때
  6. 고쳐 보기지운 글 취소선, 새 글 다른 색
  7. 결정권자: 체크로 수락
  8. 결정권자: X로 거절

체크리스트 16~23단계. 모둠 안에서 한 명을 결정권자로 정해 수락·거절을 하게 합니다.

따라 하기 4: 버전 이름 붙이고 되돌리기

  1. 파일 → 버전 기록 → 현재 버전 이름 지정
  2. 버전 이름 입력 후 저장예: 모둠 검토 전
  3. 버전 기록 보기파일 → 버전 기록 → 버전 기록 보기, 또는 시계 아이콘
  4. 이 버전 복원하기과거 시점 선택 → 복원
버전 복원은 같은 문서에서 동시에 하면 서로 영향을 줍니다. 모둠당 한 명씩 차례로 하고 나머지는 지켜본 뒤 교대합니다.

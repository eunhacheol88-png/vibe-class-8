실습 시작 전: 구글 시트 사본 만들기

원본을 직접 수정하지 않습니다. 아래 버튼을 누르면 각자 내 드라이브에 사본을 만들 수 있습니다.

출석관리 시트 사본 만들기

후원물품 시트 사본 만들기

연결형: 구글 시트 → 확장 프로그램 → Apps Script / 독립형: script.google.com → 새 프로젝트. 실행과 웹앱 배포는 서로 다릅니다.

단계 01 · 시트 사본과 구조 확인

출석관리 시트의 사본을 만들고 참여자명단(이름, 프로그램), 출석기록(날짜, 프로그램, 이름, 출석상태) 탭을 확인합니다.

AI에게 복사할 프롬프트

나는 코딩을 전혀 모르는 사회복지기관 종사자야. 출석관리 구글 시트 사본을 만들었어. 탭은 참여자명단(이름, 프로그램)과 출석기록(날짜, 프로그램, 이름, 출석상태)이야. 이 구조를 먼저 분석하고 오늘 실습 순서를 쉬운 말로 설명해줘. 아직 코드는 만들지 마.

확인: 두 탭과 열 제목을 확인하고, 실습은 반드시 본인 사본에서 진행합니다.

단계 02 · 첫 성공: 시트에 한 줄 자동 입력

구글 시트 → 확장 프로그램 → Apps Script → 코드 입력 → 저장 → 실행

AI에게 복사할 프롬프트

나는 코딩을 처음 배워. 지금 출석관리 시트 사본에서 확장 프로그램 → Apps Script를 열었어. 시트에는 출석기록 탭이 있고 열 순서는 날짜, 프로그램, 이름, 출석상태야. 실행 버튼을 누르면 출석기록의 마지막 행에 오늘 날짜, 요리교실, 김하늘, 출석을 한 줄 추가하는 가장 간단한 함수를 만들어줘. 기존 기록은 지우거나 덮어쓰지 마. SpreadsheetApp.getActiveSpreadsheet()를 사용해줘. 전체 코드와 붙여넣는 위치, 저장, 실행, 권한 승인, 결과 확인을 초보자용으로 알려줘.

확인: 출석기록 마지막 줄에 1건이 추가되는지 확인합니다. 재실행하면 1건이 더 생길 수 있습니다.

단계 03 · 출석 웹앱 화면부터 만들기

기존 출석 시트에 연결된 같은 스크립트 프로젝트 사용

AI에게 복사할 프롬프트

나는 코딩을 전혀 몰라. 사회복지기관에서 사용할 간단한 출석체크 웹앱을 만들고 싶어. 지금 구글 시트에서 앱스 스크립트를 열어놓았어. 우리 기관에는 요리교실, 미술교실, 건강교실이 있어. 프로그램을 선택하고, 참여자 이름을 선택하고, 출석, 지각, 결석 중 하나를 고른 다음 저장 버튼을 누르는 화면을 만들어줘. 글씨는 크고 화면은 깔끔하게 만들어줘. 코드를 어디에 붙여넣고 어떻게 실행하는지 초보자가 따라 할 수 있게 하나씩 알려줘. 기존 출석 자동 입력 함수는 삭제하지 마. 이 단계에서는 화면을 먼저 만들고, 저장 기능은 다음 단계에서 연결할 거야.

확인: 화면에서 프로그램, 이름, 출석상태가 선택되는지 확인합니다. 이 단계는 저장 완료가 아닙니다.

단계 04 · 웹앱에서 시트에 실제 저장

참여자명단을 읽고 출석기록에 새 행 추가

AI에게 복사할 프롬프트

방금 만든 출석체크 웹앱을 실제 구글 시트와 연결하고 싶어. 내 구글 시트에는 참여자명단과 출석기록이라는 탭이 있어. 참여자명단에는 이름과 프로그램이 적혀 있어. 출석기록에는 날짜, 프로그램, 이름, 출석상태를 기록할 거야. 웹앱에서 저장 버튼을 누르면 출석기록에 오늘 날짜와 선택한 내용이 자동으로 한 줄씩 추가되게 해줘. 프로그램을 선택하면 그 프로그램에 속한 사람의 이름만 보이게 해줘. 기존 화면과 자동 입력 함수는 유지하고 수정된 전체 코드, HTML 파일 이름, 실행 방법을 알려줘. google.script.run을 사용하고 저장 성공 또는 실패를 화면에 표시해줘.

확인: 웹앱에서 1건 저장 후 출석기록 탭에서 마지막 행을 확인합니다.

단계 05 · 웹앱 배포와 권한 확인

배포 → 새 배포 → 웹 앱. 접근 권한을 먼저 검토

AI에게 복사할 프롬프트

지금 만든 출석 웹앱을 테스트할 수 있도록 배포하고 싶어. 나는 앱스 스크립트 초보자야. 배포 → 새 배포 → 웹 앱에서 무엇을 선택하는지 클릭 순서대로 설명해줘. 실행 계정과 액세스 권한의 차이를 알려주고, 실습은 가상 데이터만 사용하며 공개 접근은 최소화하도록 안내해줘. 최초 권한 승인 과정, 테스트 주소, 코드를 수정했을 때 기존 배포를 업데이트하는 방법도 알려줘. 기존 코드는 바꾸지 마.

확인: 배포 URL을 열어보고, 실제 시트에 기록되는지 다시 확인합니다.

단계 06 · 오류 진단과 저장 검증

화면과 실제 데이터가 일치하는지 검사

AI에게 복사할 프롬프트

현재 출석 웹앱의 저장 기능을 검증하고 싶어. 프로그램별 이름 선택, 출석·지각·결석 저장, 날짜 기록, 빈 선택값 처리, 저장 버튼 중복 클릭, 서버 오류 표시를 순서대로 시험할 체크리스트를 만들어줘. 오류가 나면 실행 기록에서 무엇을 확인할지 설명해줘. 기존 기능은 유지하고 꼭 필요한 부분만 수정해줘. 실제 개인정보를 쓰지 마.

확인: 성공 메시지만 믿지 말고 시트 마지막 행을 직접 확인합니다.

단계 07 · 독립형 대시보드 기획

script.google.com에서 새 프로젝트 생성

AI에게 복사할 프롬프트

나는 코딩을 처음 배우는 사회복지사야. 이번에는 출석 현황을 한눈에 볼 수 있는 웹페이지를 만들고 싶어. 구글 앱스 스크립트 홈페이지에서 새 프로젝트를 만들었어. 앞서 만든 구글 출석부에는 참여자명단과 출석기록 탭이 있어. 이 출석부의 기록을 가져와서 전체 출석 건수, 지각 건수, 결석 건수, 프로그램별 출석 현황 그래프, 프로그램 필터를 보여줘. 같은 사람이 여러 날짜에 나오므로 사람 수가 아니라 기록 건수라고 표시해줘. 이 프로젝트는 독립형이므로 SpreadsheetApp.openById(시트ID)를 사용해줘. 먼저 시트 ID를 어디서 복사하는지, 어떤 파일을 만드는지, 코드를 어디에 붙이는지 초보자에게 설명해줘.

확인: 독립형 프로젝트와 연결형 프로젝트의 차이를 확인합니다.

단계 08 · 대시보드 그래프와 필터 검증

시트의 상태별 건수와 화면 통계 대조

AI에게 복사할 프롬프트

방금 만든 독립형 출석 대시보드를 개선해줘. 전체/요리교실/미술교실/건강교실 필터, 출석·지각·결석 건수 카드, 프로그램별 막대그래프를 유지해줘. 필터를 바꾸면 카드와 그래프가 함께 갱신되게 해줘. 새 출석기록이 추가되면 새로고침으로 다시 읽을 수 있게 해줘. 출석률은 전체 예정 횟수라는 분모가 없으니 임의로 계산하지 마. 실제 출석기록 탭과 숫자가 일치하는지 검증 절차도 알려줘.

확인: 출석기록을 1건 추가한 뒤 대시보드 새로고침으로 반영되는지 확인합니다.

단계 09 · 후원물품 관리 웹앱 기획

별도의 후원물품 시트 사본에서 시작
